RPM packages on openSUSE/Fedora ship changelogs, spec files, CVE fixes, and openQA test mappings — this server ingests all of that into a shared PostgreSQL database with pgvector for semantic search. It exposes ~19 tools over MCP (stdio), so any MCP client like Claude Code or gemini-cli can query it in natural language — "find CVEs fixed in curl last month" or "which tests cover dropped systemd features". The key insight is that the LLM reasoning stays in the client; the server is pure data retrieval, making it cheap to run as a shared service for 100 users with no per-user state.
